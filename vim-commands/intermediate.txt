=               -> for fixing the indentation
=G              -> fixing all the indentation from top to the bottom
:/word          -> find the "word"
:?word          -> find the "word"
#               -> find the same word backwards
*               -> find the same word forwards

  
when in find mode
- n for find new word
- N for find the previous word

# Navigate--------------------------------
press 'a' in the NvimTree will create a file
:split | terminal       -> create terminal horizontal
:vsplit | terminal      -> create terminal vertical
ctrl + w (h,j,k,l)      -> move between terminals windows
:NvimTreeClose          -> close the NvimTree
:NvimTreeOpen           -> open the NvimTree
:resize 10              -> will ajust the terminal
:vertical resize +5     -> will ajust the vertical terminal
